# Dataset

Большие видео и извлечённые NPZ-файлы не хранятся в репозитории.

Для препроцессинга скачайте датасет SLOVO и положите его в корень проекта:

```text
Dataset/slovo/
  annotations.csv
  data/
    *.mp4
```

Общий препроцессинг `Models/preprocess_slovo.py` берёт данные именно из этой папки.
